# Blue Plaques London

Discover London's rich history through its famous blue plaques! This iOS app helps you find and explore the commemorative plaques that mark where notable people lived and worked throughout the city.

[📱 Download on the App Store](https://apps.apple.com/app/blue-plaques-london/id427106068)

## Features

- 📍 Interactive map showing blue plaque locations across London
- 🔍 Search and filter plaques by person, location, or profession
- 📖 Detailed information about each plaque and the people commemorated
- 🗺️ Street View integration for exploring plaque locations
- 📱 Native iOS app optimized for iPhone and iPad
